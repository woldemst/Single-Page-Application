# SAP-MERN

Earlier fullstack JavaScript project with a React frontend and Node.js / Express backend.

The project focuses on CRUD functionality, user-related workflows and the connection between frontend, backend and database. It is kept as part of my development history and shows my earlier work with MERN-style application architecture.

## Features

- React frontend
- Routing with React Router
- Node.js / Express backend
- MongoDB / Mongoose data layer
- User-related backend logic
- Authentication-related dependencies
- File-upload support with Multer
- API communication between client and server

## Tech Stack

### Client

- React
- React Router
- Sass / SCSS
- React Scripts

### Server

- Node.js
- Express.js
- MongoDB / Mongoose
- JSON Web Token
- bcryptjs
- express-validator
- Multer
- Axios

## Project Structure

```text
client/   React frontend
server/   Express backend
```

## Setup

### Client

```bash
cd client
npm install
npm start
```

### Server

```bash
cd server
npm install
npm start
```
